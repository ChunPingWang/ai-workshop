## COM 共用需求（SRS 第 3 章）

### US-COM-01 未登入時的存取保護
**身為** 未登入訪客，**我想要** 在未登入時被擋在功能頁之外，**以便** 系統資料不被未授權者瀏覽。

| | |
|---|---|
| SRS 章節 | 3.1 |
| 涵蓋條文 | P-COM-01, P-COM-02, P-COM-05, P-COM-06 |
| 實作狀態 | **現況與條文不符**（見備註） |
| 優先級 | 高 |

**驗收條件**
- AC1（P-COM-01）：未登入以 GET 開啟任一功能頁（/、/report、/recon、/tos、/bankacc、/csr）→ 302 導向 /login。
- AC2（P-COM-02）：未登入呼叫資料端點不導轉，HTTP 200 回純文字——/report/data、/recon/data、/recon/detail、/tos/save、/bankacc/save、/csr/data 回 `please login`；/tos/data、/bankacc/data 回 `[]`（現況如此，兩種回法不一致）。
- AC3（P-COM-05）：GET /logout 使 session 失效並 302 到 /login；登出後再開功能頁／打資料端點，回到 AC1／AC2 的行為。
- AC4（P-COM-06）：session 閒置 30 分鐘逾時（容器預設）、以 JSESSIONID cookie 識別；同帳號可多瀏覽器同時登入。

> **備註（不符）**：以 `GET /;jsessionid=<任意值>` 開啟首頁時，請求比對不到首頁 controller，
> 由 Spring Boot welcome page 直接渲染 index 模板——HTTP 200 顯示功能選單（導覽列帳號／角色空白），
> **未依 P-COM-01 導向 /login**。全新瀏覽器第一次登入後的 302 也會落在這種 URL 上。
> SRS 未記載此行為；需決定修 SRS（如實記載）或列為升級時的已知缺陷。

### US-COM-04 報表類查詢結果的一致呈現
**身為** 任一已登入使用者，**我想要** 所有報表查詢以一致的表格格式呈現，**以便** 用同一種方式閱讀查詢結果。

|---|---|

| 實作狀態 | 已實作 |
| 優先級 | 高 |

**驗收條件**
- AC1（P-COM-20, P-COM-21）：後端回 `<table border=1 cellspacing=0>` 表格＋`total rows: N`；表頭為資料庫欄名（大寫底線）。
- AC2（P-COM-22）：畫面最多 10 筆資料列；total rows 為符合條件之總筆數，可大於 10。
- AC3（P-COM-23）：查無資料時為「無表頭、僅一個空 `<tr>`」的空表格＋`total rows: 0`。
- AC4（P-COM-24）：NULL 欄位顯示文字 `null`（現況如此）。
- AC5（P-COM-25）：欄位值原樣輸出、不做 HTML 轉義（現況如此）。
- AC6（P-COM-26）：後端 SQL 錯誤時結果區原樣顯示 `query error: …SQL=…`（現況如此，含內部訊息）。
- AC7（P-COM-27, P-COM-28）：按查詢後結果區先顯示 `查詢中...` 再被回應整個取代；等待期間按鈕不停用，連按多次以最後到達的回應為準（現況如此）。
- AC8（P-COM-29）：表格樣式由 portal.css 決定（表頭淡藍底、灰格線）。

|---|---|

- AC2（P-COM-15）：GET 類轉呼叫失敗（後端未啟動／4xx／5xx）→ HTTP 200 回 `backend error: <訊息>`，顯示於結果區。
- AC3（P-COM-16）：POST 類（/tos/save、/bankacc/save）轉呼叫失敗 → `FAIL <訊息>`，顯示於訊息區。
- AC4（P-COM-17）：轉呼叫不設逾時；後端不回應時畫面停在 `查詢中...`（現況如此）。
- AC5（P-COM-18, P-COM-19）：GET 參數直接串 URL、POST 用 form-urlencoded；資料端點缺必要參數回 HTTP 400、不轉呼叫。

### US-COM-06 輸入不驗證與固定格式慣例
**身為** 任一已登入使用者，**我想要** 了解輸入與日期金額的既定慣例，**以便** 正確解讀查詢條件與結果。

|---|---|
| SRS 章節 | 3.5、3.6 |
| 涵蓋條文 | P-COM-30, P-COM-31, P-COM-32, P-COM-33, P-COM-34, P-COM-35, P-COM-36 |
| 實作狀態 | 已實作 |
| 優先級 | 中 |

**驗收條件**

- AC5（P-COM-36）：金額為整數（元）；交易幣別 TWD、銀行帳戶幣別 NTD/USD。
